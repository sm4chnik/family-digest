# Спецификация продукта

## Цель

Сделать простой семейный ритуал: раз в N часов каждый участник получает напоминание скинуть медиа, бот собирает ответы и публикует их в общий канал.

## Роли

| Роль | Возможности |
| --- | --- |
| Участник | `/start`, часовой пояс, DND, приём напоминаний, сдача медиа в личку боту |
| Админ | Всё то же + изменение глобального интервала напоминаний, привязка канала |

Админом считается Telegram-пользователь из списка `ADMIN_IDS` (env), не «админ канала» сам по себе.

## Канал vs личка

- **Канал** — витрина. Постит только бот. Люди туда медиа не кидают.
- **Личка с ботом** — единственный способ сдать медиа и получать напоминания.

Ограничение Telegram: бот не может первым написать человеку. Пока нет `/start`, напоминаний не будет.

## Расписание раундов

- Интервал по умолчанию: **2 часа**.
- Интервал настраивается **админом** глобально (одно значение на всё семейство).
- Раунд = напоминание → окно сдачи → публикация.

### Окно сдачи

- Длительность: **30 минут** с момента старта раунда.
- Мягкий пинг: на **20-й минуте** только тем, кто ещё не сдал медиа в этом раунде и не в DND.
- В конце окна бот публикует всё принятое за раунд (плюс очередь опоздавших с прошлого раза — см. ниже).

### Опоздания

- Медиа, пришедшее **после** закрытия окна, не публикуется сразу.
- Оно ставится в очередь и уходит в **следующий** дайджест.

## Медиа

Принимаем в личку боту:

- фото
- видео
- кружок (video note)

Не принимаем (или явно отклоняем) пользовательский текст как содержимое дайджеста: в канал уходит только медиа + служебная подпись бота.

### Публикация в канал

- **Отдельный пост на каждое медиа** (не общий альбом).
- Подпись вида: `от {display_name}` (имя из Telegram / сохранённый display name).
- Без дополнительного текста от пользователя.

Если за раунд несколько файлов от одного человека — несколько постов, каждый со той же подписью.

## Часовые пояса

- У каждого пользователя свой IANA timezone (например `Europe/Moscow`, `Asia/Yekaterinburg`).
- Обязателен при онбординге (или выбирается из короткого списка + «другой»).
- Можно менять позже командой/меню настроек.
- Все «локальные» решения (DND) считаются в TZ пользователя.
- Старт глобальных раундов — по единым UTC-меткам сервера; DND лишь фильтрует, кому слать.

## Режим «не беспокоить» (DND)

- Опционально.
- Задаётся как ежедневный интервал локального времени (например `23:00`–`08:00`).
- Длина DND **не больше 12 часов** в сутки.
- Можно включить, выключить, изменить границы.
- Если время старта раунда (или мягкого пинга) попадает в DND пользователя:
  - **не шлём** этому пользователю напоминание/пинг;
  - **не** делаем отдельный «догоняющий» пинг после выхода из DND;
  - пользователь по желанию может сам написать боту и сдать медиа (попадёт в текущее окно или в очередь опоздавших — по тем же правилам времени).

## Мягкий пинг

- Время: минута **20** текущего окна.
- Кому: участники, которые:
  - уже прошли онбординг;
  - не в DND в момент пинга;
  - ещё не сдали ни одного медиа в этом раунде;
  - получили (или должны были получить) напоминание этого раунда (т.е. не были в DND на старте — уточнение реализации: пингуем только тех, кому ушло стартовое напоминание, либо всех вне DND без сдачи; **решение продукта:** пингуем всех вне DND без сдачи в этом раунде).
- Тон: мягкий, без давления («осталось 10 минут, если хочешь успеть в этот дайджест»).

## Онбординг участника

1. `/start`
2. Короткое объяснение, зачем бот.
3. Выбор часового пояса.
4. Опционально: настройка DND (можно пропустить).
5. Готово — ждём следующего раунда (или сразу можно слать медиа, если окно открыто).

## Команды / меню (минимум)

Участник:

- `/start` — онбординг / возврат в меню
- Настройки: часовой пояс, DND
- Справка: как сдавать медиа, что такое окно 30 минут

Админ:

- Показать/изменить интервал раундов (часы)
- Статус: когда следующий раунд, сколько участников, открыто ли окно
- (Опционально на старте) привязка `CHANNEL_ID`, проверка прав бота в канале

Точные тексты команд зафиксируем при реализации UI.

## Вне скоупа v1

- Комментарии/реакции как часть пайплайна сдачи
- Альбомы в канале
- Несколько каналов / несколько «семей»
- Платные подписки, веб-админка
- AI-обработка фото
- Принудительный догон после DND

Их можно добавить позже, если понадобится.
